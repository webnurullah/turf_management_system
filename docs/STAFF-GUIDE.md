# Staff quick guide

Written for receptionists, cashiers and managers. Screen names match the back-office sidebar.

## Front desk (receptionist / cashier)

| Task | Where | Steps |
|---|---|---|
| Walk-in or phone booking | **New booking** (top bar) or **Front Desk Mode → Walk-in** | Choose pitch → date → tap free slots → add rentals → enter mobile → choose *Cash at desk* or mobile payment → **Pay / Confirm** |
| Customer arrives | **Check-in** | Scan their QR (or search booking ID / phone) → check the waiver ✓ and any due amount → **Check in** |
| Collect a balance | Booking → **Collect** | Enter amount and method, add the TrxID for bKash/Nagad → print receipt |
| Sell drinks / rent equipment | **POS** | Tap items (stock is checked) → optionally add the booking balance → choose payment → **Charge** |
| Game running late / extend | Booking → **Extend** | Only possible if the next slot is free |
| No-show | Booking → **Mark no-show** | 15 min after start; the advance is kept according to policy |
| Something went wrong | **Incidents** | Log injuries, damage, behaviour or lost & found |
| End of shift | **Daily Closing** | Count notes by denomination → explain any difference → sign → manager approves |

**Remember:** full pitch and half pitches block each other automatically. If a slot is greyed out, it is
booked, on hold, under maintenance, or blocked by the linked pitch.

## Manager / owner

- **Dashboard**: today's bookings, income (cash vs digital), dues, occupancy, alerts. Use the filters for branch, pitch, source and staff.
- **Calendar**: one view for online, walk-in, academy, tournament and maintenance. Click an empty cell to book.
- **Refunds**: approve refunds above the receptionist limit (৳2,000). The policy calculation is shown; overrides need a reason.
- **Pricing and Rates**: change rates as a *new version* with an effective date. Test with the simulator first.
- **Block Slots**: maintenance, rain, events. You'll see affected bookings before confirming.
- **Weather Board**: forecast plus affected outdoor bookings. Weather-cancel lets customers choose reschedule, refund or wallet credit.
- **Collections Ledger**: every taka in and out. Entries can't be edited; use **Post reversal** to correct.
- **Reports**: P&L, cash flow, VAT, collections by staff, occupancy and more. Export to Excel, CSV or PDF.
- **Users / Roles / Permissions**: give each staff member the smallest role they need. Admin roles must use 2FA.
- **Audit Logs**: who changed what (prices, refunds, overrides, exports, logins).

## Safety rules for everyone

Never share your login. Never write customer phone numbers on paper. Never accept payment screenshots
without checking the TrxID. Call the manager for any refund or override you're not allowed to do.
