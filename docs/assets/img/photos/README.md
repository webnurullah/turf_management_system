# Photo slots

Drop real photos here (JPG, ~1600 px wide, < 250 KB each). The template shows an
illustrated turf graphic for any slot that has no file yet, so the site never
shows a broken image.

| File name                  | Used on                                   | Suggested shot |
|----------------------------|-------------------------------------------|----------------|
| hero-bg.jpg                | Home hero background (dimmed)             | Wide stadium / floodlit turf |
| hero-night.jpg             | Home hero card                            | Your pitch under floodlights |
| pitch-a.jpg                | Turf cards, turf master, media library    | Pitch A, eye level |
| pitch-a-aerial.jpg         | Home "Featured pitch"                     | Drone / top view of Pitch A |
| pitch-a-half.jpg           | Half-pitch card                           | One half with the divider net |
| futsal-indoor.jpg          | Pitch B card                              | Indoor futsal court |
| cricket-nets.jpg           | Cricket nets card, gallery                | Practice lane with stumps |
| badminton.jpg              | Badminton card, gallery                   | Court with lighting |
| gallery-night-match.jpg    | Home gallery (large tile)                 | Players mid-game at night |
| tournament.jpg             | Gallery, tournament promos                | Trophy / final match |
| birthday.jpg               | Gallery, events                           | Kids' party on the pitch |
| academy-kids.jpg           | Media library, academy                    | Coaching session |

Use your own photography or images you hold a licence for (e.g. the Unsplash
License permits commercial use). Do not copy images from Google search results —
they belong to their owners. To switch to WebP, convert the files and change
`PHOTO_EXT` in `src/lib.mjs`, then run `npm run build`.
